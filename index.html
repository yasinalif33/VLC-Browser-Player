    What this player does

    Everything VLC is known for that a browser can honestly do — no installs, no uploads, no server in between.

    • Local files
      MP4, WebM, MKV*, MP3, FLAC, WAV, OGG and more — whatever your browser can decode, it plays.
    • Network streams
      Paste a direct media URL and it joins the playlist like any file.
    • Subtitles
      Drop an .srt or .vtt file onto the playing video — it's converted and shown instantly.
    • Playlist & queue
      Reorder by playing, loop one / loop all, shuffle, previous & next.
    • Effects
      Live brightness, contrast, saturation and hue — VLC's classic adjustments, in the browser.
    • Snapshots & PiP
      Save the current frame as a PNG, or pop the video out into picture-in-picture.

    * MKV and some codecs depend on your browser's decoder support. If a file won't play here, the desktop VLC will still play it — this page never alters your files.

    Play this file in the browser player

    Browser conversion works best for smaller files. For a large stream like this one, download it once, convert it once in desktop VLC, and the result plays everywhere in the browser player.

    1. Tap Download original below and save the file to your device.
    2. In desktop VLC: Media > Convert / Save, add the downloaded file, tap Convert.
    3. Profile: Video - H.264 + MP3 (MP4). Choose a destination ending in .mp4, then tap Start.
    4. Back here: Open File and choose the converted .mp4 — it plays directly, with subtitles and speed controls.

    Open Network Stream

    Enter the address of a media file or stream. Direct links (MP4, WebM, MP3…) work best — the stream must allow cross-origin playback.
